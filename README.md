# ConnectaTel Telecommunications Analysis

## 📖 Overview

This project presents an Exploratory Data Analysis (EDA) of customer behavior for **ConnectaTel**, a telecommunications company operating in Latin America.

Using customer, usage, and plan datasets, the analysis explores how subscribers use mobile services, identifies data quality issues, detects outliers, segments customers by age and usage, and provides business recommendations to improve service offerings and customer retention.

This project was developed using **Python**, **Pandas**, **Matplotlib**, and **Seaborn** as part of the TripleTen Data Analytics Bootcamp.

## 🎯 Project Objectives

- Explore and understand three telecommunications datasets.
- Detect and correct data quality issues.
- Analyze customer behavior through descriptive statistics.
- Identify outliers using the IQR method.
- Segment customers by age and service usage.
- Generate business insights and recommendations based on data.

## 📊 Key Findings

- Identified and corrected data quality issues, including sentinel values, missing data, and invalid dates.
- Most customers belong to the **Adult** segment and exhibit **Low** or **Medium** service usage.
- Customer behavior showed right-skewed distributions for calls, messages, and call duration.
- High-usage customers were identified as a valuable segment for targeted commercial strategies.
- Outliers represented plausible high-consumption users rather than data errors and were retained for analysis.
---

## 💡 Business Recommendations

Based on the analysis, the following actions are recommended:

- Design premium plans for high-usage customers.
- Create promotional campaigns for low-usage users to increase engagement.
- Improve data validation processes to prevent sentinel values and invalid dates.
- Continue monitoring customer segments to optimize pricing strategies and customer retention.
